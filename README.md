# KitsuneDL releases

Installers for KitsuneDL, a manga downloader for Library of Kitsune.

- Download `KitsuneDL-Setup-x.y.z.exe` from [Releases](https://github.com/mihoshiho/kitsunedl-releases/releases/latest).
- Needs Windows 10 or 11 (x64).
- Updates itself after install.
- Windows may say "unknown publisher" (the app is not signed). Click **More info**, then **Run anyway**.
